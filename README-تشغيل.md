# برنامج تلاجة القدس

دفتر مبيعات ومخزون لتلاجة المجمدات: بيع قطاعي، بيع جملة، خدمة فرم وتقطيع لبضاعة العميل، شراء من الموردين، مصاريف، ديون العملاء، تقارير شهرية وتصدير Excel. نفس فكرة برنامج الصيدلية (ملف واحد + Supabase + Electron).

## 1) قاعدة البيانات (Supabase) — مشروع جديد خاص بالتلاجة
1. ادخل https://supabase.com واعمل **New project** (اسمه مثلا alqudus).
2. من **SQL Editor** الصق محتوى الملف `supabase-setup.sql` واضغط **Run**.
3. من **Authentication → Users → Add user** اعمل مستخدم (إيميل + كلمة سر) لكل واحد هيستخدم البرنامج. (وقفل Sign-ups من Authentication → Providers → Email عشان محدش غريب يسجل.)
4. من **Project Settings → API** انسخ **Project URL** و **publishable (anon) key** وحطهم في ملف `config.js`.

## 2) تشغيل البرنامج
- تجربة سريعة: افتح `index.html` في المتصفح.
- كبرنامج ديسكتوب (محتاج Node.js): 
  ```
  npm install
  npm start        # تشغيل
  npm run dist     # عمل ملف تثبيت .exe داخل مجلد dist
  ```

## 3) الاستخدام
1. **الأصناف والمخزون**: ضيف كل صنف بسعر الشراء وسعر القطاعي وسعر الجملة والرصيد الحالي.
2. **اليوم → + بيع**: اختار قطاعي أو جملة (السعر بيتغير تلقائي)، لو المدفوع أقل من الإجمالي بيتسجل الباقي آجل على العميل.
3. **+ فرم / تقطيع**: للبضاعة اللي العميل جايبها من بره — بتكتب الوزن وسعر الكيلو، ومبتأثرش على المخزون.
4. **+ شراء بضاعة**: بيزوّد رصيد المخزن ويحدّث سعر الشراء.
5. **الديون**: مين عليه كام + زرار سداد. **التقارير**: يومي/شهري، أكتر الأصناف مبيعًا، تصدير Excel.

## 4) استيراد الأصناف من Excel
من تبويب **الأصناف والمخزون ← 📥 استيراد من Excel**.
- ملف واحد فيه 3 شيتات: **لحوم** و**فراخ** و**أسماك** (البرنامج بيعرف الكاتيجوري من اسم الشيت، وأي اسم تاني بيتاخد كاتيجوري بنفس الاسم).
- الصف الأول في كل شيت عناوين الأعمدة: `الصنف` ، `سعر الجملة` ، `سعر القطاعي` ، وممكن كمان `الوحدة` ، `سعر الشراء` ، `الرصيد`. ترتيب الأعمدة مش مهم.
- أول ما تختار الملف بيعرضلك ملخص بعدد الأصناف في كل شيت قبل ما يحفظ.
- لو الصنف موجود بنفس الاسم والكاتيجوري بيتحدّث سعره، ولو مش موجود بيتضاف. تقدر تعيد الاستيراد كل ما الأسعار تتغير.
- زرار **تحميل نموذج Excel** بينزّل ملف جاهز بالتلات شيتات والعناوين.

## 5) شاشة الكاشير (كل حاجة اختيارات)
تبويب **🛒 الكاشير**: القسم (لحوم/فراخ/أسماك) ← الصنف ← الكمية (ربع كيلو، نص كيلو، 1 كيلو… أو كرتونة لو للصنف محتوى كرتونة، أو بالواحدة)، وفيه خانة لكتابة الوزن أو العدد بنفسك. السعر بيتحسب من سعر الكيلو (قطاعي أو جملة حسب الزرار فوق). العميل بيتختار من قايمة، والدفع بأزرار (كامل / آجل / ¼ / ½ / ¾). الفرم والتقطيع نفس الفكرة: نوع الخدمة ← الوزن.
- **محتوى الكرتونة** و**حد التنبيه** بيتحددوا لكل صنف من فورم الصنف، أو من عمودي `وزن الكرتونة` و`حد التنبيه` في ملف Excel.
- أنواع الخدمات وسعر الكيلو وقايمة العملاء بيتضافوا من تبويب **العملاء والخدمات**.

## 6) المخزون والتنبيهات
- كل بيع بينقص الرصيد، وكل شراء من مورد بيزوّده.
- شريط تنبيه أحمر فوق كل الشاشات بيعرض الأصناف اللي خلصت أو وصلت لحد التنبيه (الافتراضي 5)، وبعد كل فاتورة بيظهر تنبيه لو صنف من اللي اتباعوا قرب يخلص.
- **💲 تغيير الأسعار** (تبويب الأصناف): على كل الأصناف أو قسم أو صنف واحد، قطاعي/جملة/شراء، بنسبة % أو مبلغ، زيادة أو تخفيض. الفواتير القديمة مبتتأثرش، وفيه سجل بآخر التغييرات.

## 7) وضع الكاشير والمدير
من **العملاء والخدمات ← رقم المدير السري**. بعد ما تحط الرقم البرنامج بيفتح على الكاشير (الكاشير والفواتير بتاعة النهارده بس)، والمدير بيدخل بالرقم من زرار 👑. ده قفل داخل البرنامج، مش حماية كاملة على مستوى قاعدة البيانات.

## 8) تعديل المخزون (زيادة / نقص / جرد)
من تبويب **الأصناف والمخزون ← 📦 تعديل المخزون** (أو زرار 📦 مخزون جنب كل صنف، أو من تبويب اليوم):
- **➕ زيادة**: وصلتك كمية جديدة من صنف. ولو كتبت سعر الشراء الجديد بيتحدّث تكلفة الصنف.
- **➖ نقص**: تالف أو فاقد أو استهلاك.
- **📋 ضبط بالجرد**: بتكتب الرقم الفعلي اللي عدّيته في التلاجة والبرنامج يظبط الرصيد عليه.
كل تعديل بيتسجل في تبويب اليوم بتاريخه وسببه، ولو مسحته الرصيد بيرجع زي ما كان (من غير ما سعر الشراء يرجع).
